## 🧑‍💻 About Me

I build production-oriented business software: scalable Laravel backends, multi-tenant SaaS platforms, ERP/accounting workflows, integration services, automation systems, desktop agents, and reusable open-source packages.

My main focus is backend engineering with **PHP and Laravel**, with hands-on work across **Laravel 8–13**, **Filament 3–5**, modern APIs, queues, multi-tenancy, testing, CI/CD, React, React Native, Electron, and .NET desktop applications.

- 🧱 12+ years of experience, primarily in **PHP/Laravel**; also Node.js, Python, Electron/React/TypeScript
- 💼 Independent **freelancer/consultant**, taking on diverse client projects — SaaS, POS, e-commerce, booking platforms, inspection systems
- 🌐 Deep specialty in **Arabic-first, RTL-native applications** — a thread running through nearly every project I build
- 🛠️ Own full CI/CD lifecycle and infrastructure across **Docker, Linux VPS, and Cloudflare**
- 🧑‍🏫 Mentor developers alongside client work
- 🎓 Pursuing graduate studies at the Syrian Virtual University.
- 🥖 Also run **Dream Baker's** — a bakery/restaurant business, and built its full POS system myself

- 🛍️ **[Cliprz](https://cliprz.org)** — Arabic-first e-commerce theme marketplace, with a companion Node.js/Python SDK for validating third-party Blade templates. The SDK reached **v2.1** after a full security audit, fixing two P0 vulnerabilities (PHP code injection, CSS-based attribution suppression), plus seven new developer-experience features
- 🧾 **Dream Baker's POS** — Full Electron/React/TypeScript point-of-sale system built for my own bakery/restaurant, with a React Native/Expo companion app, i18n across Arabic/English/French (RTL/LTR switching), MAC+CPU HMAC license protection, expense PDF reports, and a Recharts-powered profits dashboard
- ✅ **InCheck** — Laravel-based inspection/checklist platform for structured field data collection, built and maintained with a colleague
- 🛡️ **BlueGateway** — Laravel 11 API service (companion to a larger "Blue" platform) with loss-prevention, spot-check, and dispute-management controllers, backed by a centralized `UserAccessService` for role/brand-based store access control
- 💇 **Mazyon** — Pre-launch, multi-tenant Laravel salon-booking SaaS with an embedded hiring marketplace
- 🛒 **Trend Mall** — Bilingual Arabic/English e-commerce mobile app (React Native/Expo + Laravel API) for a mall client
- ⛪ **Church Administration System** — Laravel system handling marriage certificates, polymorphic coupons, and a full checkout flow with discounts/tax/delivery/points logic
- 🔗 **Booking ↔ E-commerce automation** — n8n workflow syncing Naeem Bookings with Zid (Saudi e-commerce) via real-time webhooks
- 🎓 **Blockchain-based VANET research** — Master's thesis, *"Performance Evaluation of Blockchain-based VANETs"*: simulation debugging, realistic latency modeling, revocation-enforcement gap modeling, and comparative multi-scenario analysis — scored **100/100**
