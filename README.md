## 🧑‍💻 About Me

I'm a **Backend & DevOps Developer** based in Homs, Syria, specializing in **Laravel/PHP backends, multi-tenant SaaS, and business-critical systems**. I architect and maintain ERP, POS, booking, and e-commerce platforms, build reusable Laravel packages/SDKs, and own the full deployment lifecycle on Linux VPS infrastructure with Docker and CI/CD.

- 🧱 12+ years of experience, primarily in **PHP/Laravel**, also Node.js, Python, Electron/React/TypeScript
- 💼 Currently working as an independent **freelancer/consultant**, taking on SaaS, POS, e-commerce, and booking-platform projects
- 🌐 Deep specialty in **Arabic-first, RTL-native applications** — a thread running through nearly every project I build
- 🛠️ Own full CI/CD lifecycle and infrastructure across **Docker, Linux VPS, and Cloudflare**
- 🎓 Pursuing graduate studies at Syrian Virtual University, aiming toward a **cybersecurity master's/PhD** in Germany (Paderborn, TUM, RUB)
- 🧑‍🏫 Mentor developers alongside client work
- 🥖 Also run **Dream Baker's** — a bakery/restaurant business, and built its full POS system myself
